Student Record Management System

A menu-driven Student Record Management and Performance Analysis System developed using C Programming.

Features

- Add Student Records
- View All Student Records
- Search Students by Roll Number
- Academic Performance Analysis
- Automatic Grade Calculation
- Placement Eligibility Assessment
- Internship Eligibility Checking
- Scholarship Eligibility Checking

Technologies Used

- C Programming
- Arrays
- Conditional Statements
- Loops
- Basic Input/Output

How to Run

1. Download the source code.
2. Compile the program using GCC:

gcc student_record_management.c -o student

3. Run the program:

./student
